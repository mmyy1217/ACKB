## 让 CCE 指令接口成为可阅读的知识

CCE OPS 是一个 AI 原生的 Huawei Ascend CCE 指令接口可视化仓库。围绕 CCE 源码层的 intrinsic / builtin，建立结构化索引与原生 HTML 手册，服务算子开发、编译器研究与指令学习。

这里的“指令集”指 **CCE 可调用的指令接口集合**。接口声明、编译器内建函数与硬件机器指令分别记录，不假设它们一一对应。

## 阅读体验

| 目标 | 计划提供的能力 |
| --- | --- |
| 快速定位 | 按名称搜索，按指令族、数据类型、架构条件与验证状态筛选 |
| 看懂接口 | 完整签名、重载、参数类型、配套常量与有依据的语义说明 |
| 查看依据 | 追溯工具链版本、源文件、行号及关联 builtin |
| 理解实验 | 在接口详情中查看样例、验证结论和实验依据 |
| 跟踪演进 | 对比不同 weekly 版本中的新增、删除与签名变化 |

网页采用原生 HTML / CSS / JavaScript，面向离线阅读：紧凑表格、清晰层级、按需展开详情，把页面空间留给接口与证据。

## AI 原生，证据优先

AI 参与提取、分类、关联与解释；结构化数据和可重复执行的流程负责保存结果。每项结论都有来源，每次实验都有状态，推导与实测明确区分。人员与 Agent 共用同一份数据，网页从数据生成。
