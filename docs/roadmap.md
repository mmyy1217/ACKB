# 建设路线

## 阶段 0 · 初始化（已完成）

建立对外 README、精简 AGENTS 与范围、执行流程、路线文档。基础文档与仓库已建立。

## 阶段 1 · 接口索引（首版已交付）

固定目标包及来源，建立结构化提取与数据校验流程，覆盖 scope 中的头文件并追踪依赖。

已扫描 23 个头文件，生成 5,714 条接口记录及配套定义；保存哈希、条件、宏来源、包含关系与 29 个待处理项。原包内 23 个扫描头文件已全部匹配，安装包及内层编译器包哈希已保存；待处理结构尚未全部解析。

## 阶段 2 · 原生 HTML 手册（首版已交付）

基于真实提取结果提供搜索、筛选、紧凑表格和接口详情，展示重载、builtin 关联及来源。

已完成单文件离线页面、搜索和组合筛选、重载与类型关联、来源查看、扫描报告、JSON 导出及深链接；左右栏支持调宽，列表沿页面连续追加。浏览器回归覆盖桌面和窄屏，未请求网络资源。

## 阶段 3 · 实验与解释

先围绕 copy/DMA、FP8/FP4、MX/SF、同步建立最小探针与可靠说明，再扩展至其他指令族。

完成条件：每项实验可复现，声明、编译结果和运行结果分别呈现；未验证接口保持明确状态，不将局部实验外推为全部支持。

## 阶段 4 · 版本演进

将后续 weekly 纳入同一提取与展示流程，对比新增、删除、签名及架构条件变化。

完成条件：差异可追溯到各版本来源，能够区分工具链变化与提取器变化，不跨版本覆盖已有实验结论。

## 架构与弃用增量（静态阶段已实现）

已接入版本绑定的平台配置、逐重载三值条件核对、条件性弃用证据、筛选与导出，并提供双数据集差异工具。芯片完整预定义宏环境、包含路径传播、编译器 builtin 全量盘点及设备编译仍待完成；实际多版本差异需要第二个版本。边界见 [兼容性证据](compatibility.md)。

## AI 数据库入口（已实现）

已提供稳定 symbol / 词法签名 variant 身份、分页 JSON 查询、名称与 builtin 反查、目标条件和弃用筛选、来源与宏证据、未解析调用候选、Schema 和 AI 使用规约。HTML 与 CLI 共用加载分析层。参数语义、完整编译器 builtin、核宏环境、设备实验和真实多版本历史仍未完成，不能从查询入口的存在推断这些能力已经具备。

## ACKB 第一阶段 · 双后端索引与重点深度（已交付）

CCEC 新增 8 个可追溯主题、2,222 个 header builtin 引用，其中 2 个没有解析记录关联；已有 29 个未解析项继续公开。PTX 固定 ISA 9.4 官方来源，建立 743 节完整目录及 221 个指令条目、77 个执行/状态空间章节、39 个伪指令和 35 个特殊寄存器；补充 4 篇带引用与未知项的笔记。统一只读 CLI 已接入，保留旧 CCEC 协议。

这里的深度是选定主题的来源解释，不是每个指令的完整语义规范。网页已接入 CCEC / PTX 双后端，保留结构化数据与 CLI。下一阶段补充每种形式的参数约束、内存/同步语义、工具链接受性探针和实际设备验证；之后再做两端设计差异及共同意图映射。

## PTX 阅读层与 B300（本轮交付）

以 PTX 自身的执行、存储、操作和协作模型重组页面：7 个层次、15 个主题、3 份原创设备端教学程序，全文在主区阅读，侧栏保留术语与指令查询。补充 296 个官方语法块，覆盖全部 221 条指令；16 个特定条目有入门解释，其余逐形式语义仍待整理。主目标改为 B300，三个目标 profile 分别评估，旧 sm_89 原始快照不覆盖。没有新增设备验证结论。
