# 建设路线

## 阶段 0 · 初始化（已完成）

建立对外 README、精简 AGENTS 与范围、执行流程、路线文档。基础文档与仓库已建立。

## 阶段 1 · 接口索引（首版已交付）

固定目标包及来源，建立结构化提取与数据校验流程，覆盖 scope 中的头文件并追踪依赖。

已扫描 23 个头文件，生成 5,714 条接口记录及配套定义；保存哈希、条件、宏来源、包含关系与 29 个待处理项。原包内 23 个扫描头文件已全部匹配，安装包及内层编译器包哈希已保存；待处理结构尚未全部解析。

## 阶段 2 · 原生 HTML 手册（首版已交付）

基于真实提取结果提供搜索、筛选、紧凑表格和接口详情，展示重载、builtin 关联及来源。

已完成单文件离线页面、搜索和组合筛选、重载与类型关联、来源查看、扫描报告、JSON 导出及深链接；左右栏支持调宽，列表沿页面连续追加。浏览器回归覆盖桌面和窄屏，未请求网络资源。

## 阶段 3 · 实验与解释

先围绕 copy/DMA、FP8/FP4、MX/SF、同步建立最小探针与可靠说明，再扩展至其他指令族。

完成条件：每项实验可复现，声明、编译结果和运行结果分别呈现；未验证接口保持明确状态，不将局部实验外推为全部支持。

## 阶段 4 · 版本演进

将后续 weekly 纳入同一提取与展示流程，对比新增、删除、签名及架构条件变化。

完成条件：差异可追溯到各版本来源，能够区分工具链变化与提取器变化，不跨版本覆盖已有实验结论。

## 架构与弃用增量（静态阶段已实现）

已接入版本绑定的平台配置、逐重载三值条件核对、条件性弃用证据、筛选与导出，并提供双数据集差异工具。芯片完整预定义宏环境、包含路径传播、编译器 builtin 全量盘点及设备编译仍待完成；实际多版本差异需要第二个版本。边界见 [兼容性证据](compatibility.md)。
