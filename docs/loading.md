# 在线加载与离线交付

线上首页与数据库分开交付，离线版仍为包含全部数据的单文件 HTML。两者消费同一份校验后的快照，不删减签名、重载、来源、支持条件或关系。

## 构建边界

- `scripts/build.py` 默认生成 `dist/index.html`，以 `file://` 打开，不发起网络请求。
- `scripts/build.py --site` 生成 `dist/site/index.html` 和 `assets/`；`--output` 可指定其他专用站点目录的 HTML 路径。
- GitHub Pages 只部署 `dist/site/`，不能部署包含离线大文件的整个 `dist/`，也不能把在线首页单独作为离线文件分享。
- 构建仍只用 Python 标准库和已提交快照，不读取 CANN，不重新抓取外部文档。

## 加载与缓存

首页直接包含文字框图及八个入口，不下载数据库、不建立搜索索引。用户点击下载／更新后才加载其完整快照，完成校验前入口不可进入。CCEC 两层共用快照，AscendC 与 CCE Dialect 同理；PTX、LLVM 分别独立。

Huawei Ascend 各库共享一个较小的导航快照，包含 ID、名称、后端和 LLVM 关联边。它用于显示尚未加载的目标名称并找到目标库，不冒充完整条目，也不推断支持状态。跨库点击先检查目标下载状态；原有 ID、表单参数及深链接保留。

构建给 CSS、JavaScript、各数据库及导航文件分别计算 SHA-256，文件名包含完整内容哈希。数据同时输出确定性 gzip 与普通 JSON；现代浏览器用原生 `DecompressionStream` 解压，不支持时选择普通 JSON。数据有独立的 `ackb.site.v1` 包装，记录数据库身份。

浏览器核对长度、SHA-256、格式版本和数据库身份后才安装快照。已验证的压缩响应存入 Cache Storage；再次访问相同哈希直接读取。缓存不可用或空间不足时仍能联网阅读；损坏缓存删除后重取。缓存属于本站路径，对应数据库更新成功后清理其旧哈希文件。

不预取其他数据库。会话中已打开的库保留在内存，避免来回切换重复解析；回到首页或切换目标时，先前请求晚到也不会覆盖当前界面。

## 数据与网页更新规则

| 修改 | 重新下载范围 |
| --- | --- |
| 单库签名、证据或指令内容变化 | 对应库；导航内容变化时再更新导航 |
| 新增 / 删除 / 重命名条目或改变关联 | 对应库与导航 |
| 修改 JavaScript 或 CSS | 对应脚本或样式；未变的数据缓存继续使用 |
| 只修改首页 HTML | 小首页与发布清单；数据库、脚本和样式继续复用 |

发布清单固定本次页面、代码和数据哈希，版本号包含 HTML 本身的变化。打开页面后额外检查一次很小的最新清单；有更新显示“刷新到最新版”，保留当前深链接。刷新通过新的首页 URL 绕过旧入口缓存，不给所有数据库加时间戳。

当前页面始终使用自己的快照组合，不把新清单中的单个文件混进旧页面。若发布切换使旧数据 URL 消失，显示重试和刷新入口；旧 JavaScript URL 加载失败时，HTML 自带的恢复按钮仍有效。超时、下载或校验失败都有明确状态，不呈现伪造的空数据库。没有 Service Worker 接管首页导航。

新增后端需同步扩展打包器与加载安装函数。若改变包装协议或破坏字段兼容性，须同步升级打包器 SCHEMA、浏览器协议检查和回归；不能只改变数据格式。新字段与记录会自然改变相应内容哈希，无须人工修改版本号或要求读者清空全部缓存。

## 测量与回归

2026-11-16 的同机 Chromium 冷启动对照：HTTP 本地服务，CDP 限制下载为 1,250,000 B/s（10 Mbps）、延迟 80 ms；从导航到首页可交互。原版内嵌 HTML 为 100,792,529 B，约 81.8 秒；优化版首页、脚本、样式合计约 0.20 MB，约 0.4 秒。这是受控对照，不是实际 GitHub 网络或所有用户设备的速度承诺。

首次优化时（5c01910）的压缩快照约为 CCEC 2.88 MB、PTX 0.29 MB、AscendC 3.16 MB、CCE Dialect 0.16 MB、LLVM 1.59 MB，Huawei Ascend 共享导航约 0.53 MB。补充 c310 调用证据后，LLVM 快照约 3.22 MB；其余库未变化。随指令库增长，构建日志输出实际字节数。

构建测试验证无损解压、哈希可重复、单库更新隔离、HTML / JS / CSS 更新和旧文件清理。在线浏览器回归验证首页不加载数据库、体积预算、八层导航、冷跨库跳转、深链接、缓存与损坏恢复、失败重试、导航竞争、旧脚本恢复、无压缩 / 无缓存降级、更新提示与 1440 / 1024 / 390 / 320 布局；Pages 发布前执行。原四套离线浏览器回归独立保留。

机制参考：[原生解压](https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream)、[HTTP 缓存与版本化资源 URL](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Caching)。

## 显式下载与更新

首页八个入口显示下载／更新、传输字节与进度条，校验完成后才可打开。同库的上下层共用状态和请求，Huawei Ascend 导航数据计入下载总量。左上角切换、跨库关系和直接深链接统一经过门控；未下载时显示下载按钮，下载完成后继续原导航。下载过程中切换目标不会被迟到的结果抢回。

已缓存的当前哈希无需用户重新下载，进入时仍检查完整性；损坏、超时或失败保留重试入口。缓存不可写时本次会话仍可使用，下次访问需再次下载。进度按实际接收字节计算，字节收齐后显示校验中，只有哈希、解压与数据身份检查完成才进入。

旧哈希存在而当前哈希缺失时显示更新。后台发现最新清单的数据哈希变化，也会将相应入口锁定为更新；点击后刷新页面固定新版本，再下载目标库，避免新数据与旧代码混用。仅页面或样式变化沿用原有刷新提示，不使未变化的库重新下载。离线单文件已包含全部库，不显示下载控件。
