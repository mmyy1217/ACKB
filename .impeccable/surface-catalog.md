# ACKB 双后端知识索引与 PTX 阅读页面

模式：PTX 主入口为 Read，指令速查与官方手册目录为 Operate；CCEC 保持既有 Operate 与详情阅读。沿用用户已确认的原生 HTML、单文件离线、黑白灰高密度界面。

## Direction contract

THESIS：PTX 面向初学者与 AI，先理解 GPU 程序设计，再随手核对指令语法、目标条件与来源；CCEC 固定 950 / A5，默认通过封装接口理解调用，切换到 Intrinsics 核对完整 builtin 身份与独立条件。

OWN-WORLD：细线分区、系统中文字体和代码等宽字体，无装饰色或卡片。延续“器件规格表”的灰阶与原生控件，正文以独立阅读字号承载解释。视觉令牌与组件规范见 `DESIGN.md`。

STORY：切换 PTX 进入全景，从七个独立章节选择主题；正文持续阅读，右侧查术语与代码指令，返回后继续原位置。需要完整语法时进入主阅读区的条目；指令速查、官方目录与来源覆盖为次级入口，不把 CCEC 分类映射成学习顺序。

FIRST VIEWPORT：40px 桌面紧凑顶栏保留 ACKB、后端、目标、搜索和导出。PTX 左侧章节默认 210px，CCEC 左栏仍为 136px；右侧默认 330px，至多 1220px 且无保存偏好时为 300px。分隔线可拖动或键盘调宽并记住偏好。PTX 正文标题 23px、段落 14px / 1.85、至多 74ch，右侧是随手查。至多 800px 时导航转为原生选择器，正文标题 20px、段落 13px，查阅内容顺序排在正文后。

FORM：学习正文、轻量查阅与证据折叠块共用白底、灰线和文字层级；右栏可收起，桌面左栏为可折叠章节组。索引保留 26px 单行表、每批 60 组连续追加和全结果进度。阅读正文不显示指令数量轨道。CCEC 复用列表与详情布局，左栏仅保留指令族；顶栏只读目标、待确认开关与覆盖入口承接范围和证据说明。

FINISH：与 `web/index.html`、`web/app.js`、`web/knowledge.js`、`web/ptx-reader.js`、`web/style.css` 对照；本轮 PTX 1440 / 1024 / 390 / 320px 与完整程序 1024 / 390 / 320px 截图经 reviewer 确认可接受。截图是回归证据，无新增交付位图资产。

## 共享交互与索引

索引结果摘要显示当前视口范围 / 筛选结果总数；最左端 16px 轨道按全部结果映射，可拖动、点击、用方向键、Page Up / Down、Home / End 定位，必要时追加至目标并保留已有行。空结果、报告和 PTX 学习正文隐藏轨道。搜索与筛选重置连续加载；深链接保留选中条目与目标。

顶栏以“CCEC 编程接口 / CCEC Builtins / PTX”切换封装接口、唯一 builtin 和 PTX 全景主题。JSON 导出保留当前后端、来源、筛选与验证状态；官方来源链接需联网，页面内容与交互离线可用。

## CCEC 内容与筛选

CCEC 固定 Huawei Ascend 950PR_9579 / NpuArch 3510；顶栏提供域、文件、只读“950 / A5”、“显示待确认”、搜索、“说明 / 覆盖”和导出，隐藏重复视图标题。没有 CCEC 芯片、架构、弃用或源码证据选择器。左栏只显示指令族，窄屏同样只保留原生指令族选择器。

默认 CCEC 编程接口按命名空间与名称分组，显示 368 个至少一个声明条件符合的调用接口（357 个封装及 11 个搬运直连入口）；启用待确认后加入 191 个，共 559 个；66 个全排除接口不进入主目录。CCEC Builtins 每个完整 builtin 一行，默认 1514 个条件符合项，启用待确认加入 2839 个，共 4353 个。Intrinsic 仅按显式入口声明条件判断，不继承封装条件或名称级源码支持矩阵；只有函数体引用、缺少入口条件的 builtin 保留待确认。条件符合不等于可编译或设备支持。

列表显示名称、指令族、950 条件与右对齐的声明数或有类型声明形式数；形式未确定显示破折号。详情保留签名、参数、原始实现、来源、条件和关联 builtin，沿关系在封装与 Intrinsics 之间跳转。进入未知关系目标时显式打开待确认；排除来源仅作为单条证据查阅。旧记录 ID 与深链接仍可访问，旧芯片参数不能改变固定 950 范围。

原始声明、配套定义与知识解释从详情或“说明 / 覆盖”进入，不新增侧栏类型导航。覆盖页先显示封装与唯一 builtin 的符合、未知、排除计数，再以原生折叠块呈现来源覆盖和知识说明。全部 5714 条接口来源、8 个知识主题、337 项关联缺口与 207 个仅文本候选仍保留在数据层；完整多架构审计通过 CLI 查询。原始记录详情保留源码引用、宏条件、弃用证据及 950 架构判定。名称级关联不保证当前重载、类型或模板适用，编译、运行和性能仍未验证。

JSON 导出保留固定目标、当前层级、待确认开关、唯一 op、关系边、相关原始来源记录及完整文件清单；当前范围的入口、参数形式与调用者独立保留来源条件。原始数据不因页面固定目标被裁剪。

本轮复用灰阶、原生选择器、复选框与折叠来源块；复选框 `accent-color` 引用既有 `ink`，移除旧架构菜单样式，不新增视觉令牌。构建、77 项单元测试及 A5 / PTX 浏览器回归通过；`.impeccable/review/a5-{interfaces,intrinsics}-{1440,1024,390,320}.png` 为本轮双层桌面与窄屏审阅截图；独立 reviewer 已核对全部 8 张，结论为 ship，无实质修复项。

## PTX 学习与随手查

七个独立章节为 PTX 全景、执行模型、存储与数据、基本指令、协作与异步、矩阵计算、完整程序，共 15 个学习主题。正文提供概念解释、代码、关联资料、下一主题和可展开的依据 / 验证状态；完整程序包含 3 份原创设备端教学 kernel，说明启动前提及未验证状态。

术语按钮与代码旁的“查”只更新右侧随手查，保留正文和桌面滚动位置。代码查阅保留触发行，可查看已有的形式解释和目标条件；未整理的操作数解释明确说明。只有“在正文阅读完整条目”等导航操作才替换主阅读内容。“返回正文”恢复原入口焦点；窄屏查阅时滚到查阅区，返回时滚回原入口。右栏收起后由右下角入口重新展开。

次级入口为指令速查（221）、官方手册目录（743）与来源覆盖。全部 221 条指令保留官方语法；16 个特定条目有中文示例解释，不代表全变体语义覆盖。完整条目在主阅读区呈现官方语法、形式解释、目标与版本限制、父子章节及来源哈希。完整手册描述未复制入库。

默认目标为 NVIDIA B300 / sm_103a，可选 sm_103、sm_103f、sm_103a；目标写入深链接。文档条件筛选为全部状态、文档支持、部分形式、文档排除、待确认，仅用于索引，阅读时隐藏。历史 sm_89 快照仅留作来源追溯，不再作为默认只读目标。

固定 PTX ISA 9.4 / CUDA 文档归档 13.4.3 的来源与哈希；语法、规则、原创解释及已有证据离线可读，官方原文链接需联网。基础、family-specific 与 architecture-specific 目标分别核对。文档支持和示例语义推导均不等于设备验证；编译、运行、性能分别保留未验证状态。

## CCEC 参数选择与搬运路径补充

Intrinsic 详情顶部使用既有 `.overloads` 原生选择器，直接显示所选签名与参数表；无完整签名时禁用并解释。关联封装参数独立选择并标明与 builtin 参数的区别，选择写入深链接。入口来源和全部调用来源仍保留折叠证据。

左栏恢复 DMA、矩阵、访存等大类，不设搬运路径子项；列表同一行保留路径，搜索支持 GM2UB / GM2L1。CCEC 编程接口新增已追踪的搬运直连入口，名称后显示“直连”，与封装同处调用接口层。详情顶部使用原生选择器展示“950 源码调用形式”，逐项列出实参表达式与源码类型，折叠块提供调用源码、文件哈希、核保护与架构 include 路径；这些不是编译器正式形参或设备验证。

## AscendC / CCE Dialect 阅读入口

沿用黑白灰高密度列表、原生选择器和详情布局，不新增视觉令牌。顶栏增加 AscendC 高层 API / 底层接口、CCE Dialect 语义 Op / Intrinsics，左栏仍只保留大类。AscendC 保留完整声明形式与当前形式的条件来源，选择写入深链接。跨层名称关联明确为候选；局部条件符合不等于实现或设备支持。Dialect 仅计具体 LLVM 符号，5 个没有静态映射的 MLIR 条目在覆盖页独立展开。所有形式、来源、限制和未解析项离线可读且可导出。

搜索结果为空或部分隐藏时，使用原有灰色说明与文本按钮提示待确认条目数量；不新增侧栏入口。Reg 调用证据沿用详情折叠块，默认不占列表空间。统一名称与解释见 CONTEXT.md。
