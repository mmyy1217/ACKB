# ACKB 双后端知识索引页面

模式：Operate，详情区兼顾 Read。沿用用户已确认的原生 HTML、单文件离线、黑白灰高密度工作台；本轮扩展 ACKB 品牌与 CCEC / PTX 知识浏览，不重建视觉方向。

## Direction contract

THESIS：选择目标后端、检索条目、核对条件与来源在同一个工作面完成。首屏直接出现真实数据。

OWN-WORLD：细线分区、系统中文字体和代码等宽字体，无装饰色或卡片。视觉令牌与组件规范见 `DESIGN.md`。

STORY：先选 CCEC / PTX，再按内容视图、搜索与条件缩小范围；选中条目后在旁边阅读声明、文档规则、主题解释与来源。关联按钮连接章节、笔记或声明，保留验证边界。

FIRST VIEWPORT：40px 桌面顶栏依次放置 ACKB、CCEC / PTX 原生选择器、视图标题、当前后端筛选、搜索、版本与仓库、JSON 导出。分类导航默认 136px、详情默认 330px，两侧分隔线支持拖动和键盘调宽并记住偏好。主列表为 26px 单行表，沿文档连续展开，每批 60 个名称组；顶栏、摘要、表头与侧栏吸附。801–1100px 隐藏顶栏视图标题和元信息；至多 800px 导航折叠为选择器，筛选与搜索换行，详情顺序展开并提供返回列表。

FORM：保持既有紧凑表格与并置详情结构（原结构 seed:2ee58f22080cd9b8）。CCEC 展示接口名、指令族、域与重载数；PTX 展示指令 / 章节、类别、文档条件与章节号。详情以文字、灰底证据块和可展开的原始结构化记录承载解释，不新增视觉令牌。

FINISH：实现与 `web/index.html`、`web/app.js`、`web/knowledge.js`、`web/style.css` 对照；PTX 1440 / 1024 / 390 / 320px 截图完成布局核对，独立 reviewer 已确认布局可接受。截图是页面回归证据，无新增交付位图资产。

## 共享交互

结果摘要显示当前视口名称组范围 / 筛选结果总数，并标明当前指令族或筛选范围。最左端 16px 进度轨道按全结果映射，可拖动、点击、用方向键或 Page Up / Down、Home / End 定位；必要时追加至目标并保留已有行。空结果与报告隐藏轨道；窄屏阅读详情时进度明确显示条目序号。两端共享连续追加、栏宽偏好、搜索、深链接和返回列表。

切换后端进入该后端指令视图并重置筛选。URL 记录后端及选中条目，原有 CCEC 深链接兼容。知识详情提供复制记录、复制链接、来源证据、验证状态和可键盘切换的标签页；关联跳转清除遮挡目标的筛选，定位相应条目。导出覆盖当前筛选结果，附后端、来源、筛选和验证状态；报告导出对应后端记录。
