# ACKB 双后端知识索引与 PTX 阅读页面

模式：PTX 主入口为 Read，指令速查与官方手册目录为 Operate；CCEC 保持既有 Operate 与详情阅读。沿用用户已确认的原生 HTML、单文件离线、黑白灰高密度界面。

## Direction contract

THESIS：PTX 面向初学者与 AI，先理解 GPU 程序设计，再随手核对指令语法、目标条件与来源；CCEC 以 intrinsic / builtin 唯一 op 为主目录，入口声明和上层封装分层核对。

OWN-WORLD：细线分区、系统中文字体和代码等宽字体，无装饰色或卡片。延续“器件规格表”的灰阶与原生控件，正文以独立阅读字号承载解释。视觉令牌与组件规范见 `DESIGN.md`。

STORY：切换 PTX 进入全景，从七个独立章节选择主题；正文持续阅读，右侧查术语与代码指令，返回后继续原位置。需要完整语法时进入主阅读区的条目；指令速查、官方目录与来源覆盖为次级入口，不把 CCEC 分类映射成学习顺序。

FIRST VIEWPORT：40px 桌面紧凑顶栏保留 ACKB、后端、目标、搜索和导出。PTX 左侧章节默认 210px，CCEC 左栏仍为 136px；右侧默认 330px，至多 1220px 且无保存偏好时为 300px。分隔线可拖动或键盘调宽并记住偏好。PTX 正文标题 23px、段落 14px / 1.85、至多 74ch，右侧是随手查。至多 800px 时导航转为原生选择器，正文标题 20px、段落 13px，查阅内容顺序排在正文后。

FORM：学习正文、轻量查阅与证据折叠块共用白底、灰线和文字层级；右栏可收起，桌面左栏为可折叠章节组。索引保留 26px 单行表、每批 60 组连续追加和全结果进度。阅读正文不显示指令数量轨道。CCEC 既有布局与交互不变。

FINISH：与 `web/index.html`、`web/app.js`、`web/knowledge.js`、`web/ptx-reader.js`、`web/style.css` 对照；本轮 PTX 1440 / 1024 / 390 / 320px 与完整程序 1024 / 390 / 320px 截图经 reviewer 确认可接受。截图是回归证据，无新增交付位图资产。

## 共享交互与索引

索引结果摘要显示当前视口范围 / 筛选结果总数；最左端 16px 轨道按全部结果映射，可拖动、点击、用方向键、Page Up / Down、Home / End 定位，必要时追加至目标并保留已有行。空结果、报告和 PTX 学习正文隐藏轨道。搜索与筛选重置连续加载；深链接保留选中条目与目标。

切换后端时，CCEC 进入底层 op，PTX 进入全景主题。JSON 导出保留当前后端、来源、筛选与验证状态；官方来源链接需联网，页面内容与交互离线可用。

## CCEC 内容与筛选

导航为底层 op、入口声明、上层封装、原始记录、待解析入口、配套定义、知识主题和扫描报告；主视图保留指令族导航。4353 个唯一 op 按完整 builtin 身份每行一个，其中 1523 个有显式 alias、2830 个仅有完整 builtin 调用依据；有类型声明形式数与来源记录数分开，形式未确定显示破折号。5714 条原始接口记录及旧 ID 保留：1525 条入口声明、4182 条封装、7 条待解析入口。原始记录视图按名称组审计，不用于 op 计数。

op 详情按唯一身份、架构条件、参数形式、入口来源和上层调用者展开；原生折叠块保留完整签名、原始条件、位置与哈希。关联文字按钮在 op 与原始记录之间导航，旧记录深链接进入对应层。8 个知识主题仍可跳回具体声明；原始记录详情保留来源声明选择器、完整签名、条件、来源与实验记录。

顶栏为域、文件和架构 / 弃用折叠入口。展开面板宽 320px，芯片、宏场景、条件与弃用使用原生选择器，核目标只读。无哈希首次打开默认 Ascend950PR_9579 和“符合或待确认”；返回 CCEC 时同样恢复默认目标。已有深链接保持其目标设置。Escape 或点击外部关闭面板；窄屏限制在视口内。条件符合不等于可编译或设备支持。

底层 op 的架构条件只汇总显式入口声明，不继承调用者条件、同名封装或名称级引用矩阵；弃用与源码证据选择器在主 op 视图禁用。原始记录层的源码证据选择器位于架构 / 弃用面板内，须先选择芯片或 NpuArch。选中证据状态时清除声明条件筛选；更换芯片、架构或视图时清除证据筛选，深链接保留有效证据状态。详情先给出当前架构的源码判定、名称引用计数与核保护线索，再按需展开代表性引用、文件位置与哈希、引用处条件和架构选择路径，以及全部 14 个架构的判定。完整引用通过 support 查询分页获取。

扫描报告先展示唯一 op 与记录层级计数，单列 337 项关联缺口和 207 个仅文本候选，不自动生成 op。op JSON 导出保留关系边、相关原始记录和完整来源文件清单。原有证据报告展示 5714 条接口记录 × 14 个 NpuArch、74 个芯片配置、1608 个已核验源码文件、目标架构状态计数和扫描告警；JSON 导出保留筛选、证据来源哈希与代表性引用路径。名称级关联不保证当前重载、类型或模板形式适用；核保护线索不证明其他核不支持，声明排除但存在同名引用时保留冲突。编译与设备验证仍未执行。

本轮为既有 Operate 页面的 op 分层改写，复用灰阶、原生选择器与折叠来源块，不新增 CSS 或令牌。`ccec-ops-1440.png`、`ccec-ops-1024.png`、`ccec-ops-390.png`、`ccec-ops-320.png` 位于 `.impeccable/review/`，reviewer 结论为 ship。

## PTX 学习与随手查

七个独立章节为 PTX 全景、执行模型、存储与数据、基本指令、协作与异步、矩阵计算、完整程序，共 15 个学习主题。正文提供概念解释、代码、关联资料、下一主题和可展开的依据 / 验证状态；完整程序包含 3 份原创设备端教学 kernel，说明启动前提及未验证状态。

术语按钮与代码旁的“查”只更新右侧随手查，保留正文和桌面滚动位置。代码查阅保留触发行，可查看已有的形式解释和目标条件；未整理的操作数解释明确说明。只有“在正文阅读完整条目”等导航操作才替换主阅读内容。“返回正文”恢复原入口焦点；窄屏查阅时滚到查阅区，返回时滚回原入口。右栏收起后由右下角入口重新展开。

次级入口为指令速查（221）、官方手册目录（743）与来源覆盖。全部 221 条指令保留官方语法；16 个特定条目有中文示例解释，不代表全变体语义覆盖。完整条目在主阅读区呈现官方语法、形式解释、目标与版本限制、父子章节及来源哈希。完整手册描述未复制入库。

默认目标为 NVIDIA B300 / sm_103a，可选 sm_103、sm_103f、sm_103a；目标写入深链接。文档条件筛选为全部状态、文档支持、部分形式、文档排除、待确认，仅用于索引，阅读时隐藏。历史 sm_89 快照仅留作来源追溯，不再作为默认只读目标。

固定 PTX ISA 9.4 / CUDA 文档归档 13.4.3 的来源与哈希；语法、规则、原创解释及已有证据离线可读，官方原文链接需联网。基础、family-specific 与 architecture-specific 目标分别核对。文档支持和示例语义推导均不等于设备验证；编译、运行、性能分别保留未验证状态。
